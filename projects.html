KV [8 → 4 → 2]adaptive cache precision

Dynamic KV Cache Scheduler

A hybrid dynamic quantization framework for transformer-based video models. It adjusts KV cache precision based on scene complexity and motion, using an OpenCV-powered information score to schedule precision in real time.

Rotation-based outlier mitigation and sink-token preservation help stabilize low-bit inference.

32% less KV cache memory, within 1.2% of full-precision accuracy. 14% higher throughput and 18% lower VRAM use versus uniform baselines.
